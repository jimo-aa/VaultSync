# VaultSync V2.0 移动端原型（`<720` 档）

> 设计基线：`docs/v2.0/`（现行）。与桌面端原型（`../v2.0/`）**共用同一份内核**，只在**外壳**上分叉。
> 纯静态、零依赖、无构建：**直接双击 `index.html` 即可在浏览器中打开**。
> 全部为 Mock 数据，不含任何真实加密、同步与存储逻辑。

---

## 一、这一端是什么

`docs/v2.0/04` §1.1 把「展示形式」定义为**同一核心引擎在不同设备、尺寸、网络与状态下的呈现与交互方式**。
移动端就是其中的 `<720` 档，`docs/v2.0/03` §2.2 给了它的全部外壳规则：

| 维度 | 移动端规则 | 出处 |
| --- | --- | --- |
| 导航 | **底部 Tab（5 项）**：保险箱 / 同步 / 设备 / 安全中心 / 设置 | `03` §2.2 |
| 内容列 | **单栏列表** | `03` §2.2 |
| 分栏视图 | **不提供** —— 视图切换器只显示可用项，**不是置灰** | `03` §2.2、`04` §1.2 |
| 顶栏 | 标题 + 溢出菜单；**搜索为全屏页** | `03` §2.2 |
| 详情 | **全屏路由** | `03` §2.2 |
| 对话框 | **全屏或底部面板** | `03` §2.2 |
| 审计日志 | **卡片流**（不是完整表格） | `03` §2.2 |
| 列表项操作 | **长按 → 底部动作面板** | `03` §2.2 |
| 快捷键 | 仅 `Esc`（等效硬件返回） | `03` §2.2 |
| 触控目标 | ≥ 44×44 | `03` §2.2 |
| 页边距 | `sp.4` | `03` §2.2 |

`docs/v2.0/03` §4.3 的手机窄屏主壳线框图还规定：**Tab 切换不重建页面状态，滚动位置按 Tab 记忆**；
本原型据此实现了**每 Tab 一条独立导航栈**（`VS.nav.stacks`），栈顶与滚动位置都会在切换时保留。

## 二、演示口令

| 口令 | 效果 |
| --- | --- |
| `1234` | 主密码解锁 → 真实保险箱 |
| `88888888` | 伪装密码 → 伪空间 |
| 任意其他输入连续 3 次 | 暴力破解保护（错误码 2，30 s 冷却） |

移动端**以生物识别为主路径**（`04` §1.2、§六），锁屏首屏即「用生物识别解锁」，主密码为次路径。

## 三、怎么操作这个原型

它模拟的是一台手机，所以交互语汇与桌面端不同：

| 动作 | 桌面端 | 移动端（本原型） |
| --- | --- | --- |
| 打开条目 | 双击 | **单击** |
| 条目操作 | 右键菜单 | **长按**（触屏）或 **鼠标右键** → 底部动作面板 |
| 快捷操作 | 无 | **左滑**列表行（原型里用鼠标按住向左拖即可） |
| 返回 | 无 | 点左上角 `‹` 或按 **Esc** |
| 二级界面 | 居中弹窗 | **底部面板**（从下往上滑出） |

窗口宽度 `< 720px` 时自动去掉手机外框铺满屏幕，可直接在真机浏览器里看。

## 四、目录结构

```

├── assets/
│   └── mobile.css      # 移动端外壳（状态栏/应用栏/底部 Tab）+ 移动端专属组件（底部面板/动作面板/左滑行）
├── js/
│   ├── mui.js          # 移动端 UI 原语（VS.mui）：page/appbar/tabbar/screen/mrow/mlist/mcard/
│   │                   #   sheet/actionSheet/confirmSheet/mfullscreen/overviewBar/attachSwipe …
│   ├── views-vault.js  # 保险箱域：列表与网格、文件夹钻取、文件详情全屏页、检索全屏页、已删除与待清理
│   ├── views-sync.js   # 设备与配对 / 同步总览 / 队列 / 单任务详情 / 冲突 / 策略 / 阅后即焚
│   ├── views-security.js # 安全中心四段 / 审计卡片流 / 隐写术 / 全屏强告警
│   ├── views-system.js # 设置及全部子页 / 授权与订阅 / 恢复向导 / 轮换 / 迁移 / 关于 / 诊断
│   └── app.js          # 外壳 · Tab 栈导航 · 锁屏 · 演示控制台
└── README.md
```

### 为什么 `../v2.0/js/` 被引用而不是复制

`mobile/index.html` 直接加载 `../v2.0/js/core.js`、`ui.js`、`data.js`，只有视图与外壳是本目录自己的。
这正是产品自身的原则——**「一套内核、受管外壳」**（`docs/v2.0/03` §1.1 目标 5）——在原型工程上的投影：

- 两端共享同一份**错误码文案出口**（`VS.ERR` 14 码、`VS.RELAY_ERR` R1–R17）、同一套 **Design Token**、同一份 **Mock 语料**；
- 改一处文案或状态语义，两端同时生效，不会出现「桌面说 A、手机说 B」的漂移；
- 代价：`mobile/` 不能脱离 `v2.0/` 单独拷贝——这是**有意的**，因为它本来就不是独立产品。

## 五、移动端减配的如实声明（`docs/v2.0/04` §1.2）

原则 11 要求「减配如实声明，不得让用户以为桌面有的手机也有」。本原型把每一条都落到了界面：

| 能力 | 桌面 | 移动端 | 本原型里的呈现 |
| --- | --- | --- | --- |
| 后台同步 | 应用运行期间进行（无守护进程） | **尽力而为**（`CAP_MOBILE_MANAGED`） | 设置页同步区固定文案「**移动端后台同步为尽力而为：系统可能在省电模式暂停**」 |
| 持续监听（P2P 入站） | 支持 | **仅前台** | 设备页在非前台时显示「**待唤醒**」而非「在线」 |
| 系统通知 | 原生通知 | **移动推送（受管）** | 设置页渠道矩阵写「应用内 + 系统推送」 |
| 生物识别 | 平台能力（可选） | **生物识别为主** | 锁屏首屏是生物识别；不可用时该区块**隐藏**（错误码 4/5 → 隐藏而非置灰） |
| 截屏保护 | 不适用 | **支持**（`FLAG_SECURE` / iOS 遮罩） | 安全中心显示**本端能力**，不照抄桌面的「不适用」 |
| 三视图 / 分栏 | 完整 | **无分栏，列表为主** | 视图切换器**只显示「列表 / 网格」**，不出现「分栏」 |
| 配对载体 | 发现式 · 邀请码 · 扫码 · 手动 | **发现式 · 扫码为主** | 配对向导把「扫码」排第一；相机不可用时该项**不渲染** |

## 六、实现纪律（与桌面端同源）

1. **能力三档**（`03` §1.2）：能力位未置位时**整块不渲染**（返回 `null`），其次置灰并写明原因，**绝不降级为假装成功**。
   侧栏「演示控制台」可逐位切换 `VS.CAP` 验收。
2. **错误码全 14 码**（`03` §3.2）：文案统一来自 `VS.ERR`；码 12 用 info 语气而非红色错误态；码 9 只切只读横幅、**不弹错误框**。
3. **中继错误空间独立**（`08` §3.4）：`VS.RELAY_ERR` 定义 R1–R17 的**用户可见映射**，界面**不得出现裸 R 码**。
4. **擦除强度如实**（`05-02` §三.4/§四.3）：徽标显示引擎原值；`crypto_only` / `unknown` 文案必含「**介质覆写未执行**」；「安全擦除」字样仅在 `platform_secure` + 平台安全删除位成立；物理删除失败显示「**介质擦除待完成**」。
5. **写冻结矩阵**（`03` §3.1）：`VS.derive.denyWrite()` 是唯一判据，只读（9）/ 维护态（10）下的可用与禁用清单在界面上逐条可见。
   例外：维护态下**擦除 / 销毁仍允许**（文档规定的唯一例外）。
6. **不谎报能力**（`04` §3.6）：无接口的可视化整行不渲染；有接口的标注来源。找原图的「卷剩余空间」在两端都**不渲染**。
7. **intl 强制**（`03` §6.1）：日期 / 数字 / 体积 / 相对时间 / 速率全部走 `VS.fmt`，禁止手写拼接。
8. **原型约束**：纯静态、零依赖、无框架、无构建、**不使用 ES Module**；二级界面**一律底部面板**，不使用桌面端的居中弹窗（`UI.modal`）。

## 七、明确不虚构的部分

跟随 `docs/v2.0` 的边界，以下内容**文档未定义，因此原型不虚构**：

- 商业订单、购物车、支付方式、结算、退款、发票 —— `12` §1.3 列为非范围；套餐价格使用**可配置占位**。
- 试用期 —— `12` §6.3 明确反对；授权页无任何试用倒计时。
- 语音 / 视频通话界面 —— `05-04` 的「通信」仅指 Noise 信道与一次性 burn 分享通道。
- 「只存不解」节点 —— `13` 记录为架构空白但未立项，原型不提供可操作 UI。
- 「异地检测」落锁 —— 架构上无该接口，设置页该项 **⛔ 不渲染**。

## 八、本地验证

```powershell
# 方式一：直接双击
start prototype/mobile/index.html

# 方式二：静态服务器（注意要在 prototype/ 下起，才能访问到 ../v2.0/）
python -m http.server 8080 --directory prototype
# 然后访问 http://localhost:8080/mobile/
```

验收建议路径：锁屏（生物识别为主）→ 保险箱列表 → 长按条目看动作面板 → 左滑条目 → 打开文件详情（5 段）→ 检索全屏页 → 设备页「待唤醒」与配对向导（扫码优先）→ 同步总览与队列甘特 → 安全中心四段（审计卡片流）→ 隐写嵌入向导的容量协商 → 设置全部子页（**注意减配声明**）→ 授权页 → 恢复 / 轮换 / 迁移 → **演示控制台逐位切换能力位**。
