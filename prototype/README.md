# VaultSync 原型 · 版本索引

纯静态、零依赖、无构建的高保真 HTML+CSS+JS 原型。**直接双击 `index.html` 即可在浏览器中打开**版本选择页，或直接进入某一端。

```
prototype/
├── index.html      # 版本索引（落地页）
├── README.md       # 本文件
├── v1.0/           # 已冻结：对应 docs/v1.0/，只读，不得就地修改
│   ├── index.html  #   单文件结构（含全部页面骨架与 SVG 图标库）
│   ├── styles.css  #   设计 Token + 组件样式
│   └── app.js      #   Mock 数据与交互逻辑
├── v2.0/           # 现行 · 桌面端（≥1280 档）：对应 docs/v2.0/
│   ├── index.html
│   ├── assets/     #   tokens / base / components / views 四层样式
│   ├── js/         #   core / ui / data + 4 个视图模块 + app（外壳与路由）
│   ├── _requirements/  # 从 docs/v2.0 提取的 UI 面清单（实现依据）
│   └── README.md   #   路由、弹窗、组件与实现纪律清单
└── mobile/         # 现行 · 移动端（<720 档）：同一设计基线，受管外壳
    ├── index.html  #   桌面浏览器中以手机外框呈现；窗口 <720px 自动铺满
    ├── assets/     #   mobile.css（外壳与移动端组件）；Token/基础/组件复用 ../v2.0/assets/
    ├── js/         #   mui.js（移动端原语）+ 4 个视图模块 + app（Tab 栈导航与外壳）
    └── README.md
```

> **「一套内核、受管外壳」**：`mobile/` 刻意**不复制** `v2.0/js/{core,ui,data}.js`，而是直接引用，
> 保证两端共享同一份内核、Token 与错误码文案出口，避免双份漂移。两端只在**外壳**上分叉。

## 演示口令（三代/端一致）

| 口令 | 效果 |
| --- | --- |
| `1234` | 主密码解锁 → 真实保险箱 |
| `88888888` | 伪装密码 → 伪空间（空保险箱，真实数据隔离） |
| 任意其他输入 3 次 | 触发暴力破解保护（30s 延时） |

「生物识别」按钮模拟平台认证流程（桌面端 Windows Hello / 移动端为主路径）。

## 约定的纪律（两代共同遵守）

- **纯静态、零依赖、无构建**：不引入框架或包管理器；V2.0 亦不使用 ES Module（`file://` 下会被 CORS 拦截）。
- **视觉 Token**：暗色 `#10131A` 底 + 香槟金 `#D9B25F` 点缀；V2.0 的 Token 以实现值 `#B98F2E`（亮色）为准，并追加 `maintenance` / `erase` / `quarantine` / `stale` 四语义色。移动端**不新增 Token**，只做布局与外壳分叉。
- **文件列表交互**：
  - 桌面端（`v2.0/`）：单击选中、Ctrl/Shift 多选、双击打开、右键菜单。
  - 移动端（`mobile/`）：单击打开、**长按 = 动作面板**、左滑 = 等价降级。
- **二级界面不变式**：
  - 桌面端：一律**居中弹窗（modal）**，不使用滑入抽屉。
  - 移动端：一律**底部面板（bottom sheet）**，不使用居中弹窗（`UI.modal`）。
- **动效**：≤300ms、`ease-out`、只动 `transform` / `opacity`，并支持 `prefers-reduced-motion`。
- **减配如实声明**（`docs/v2.0/04` §1.2）：每端被减掉的能力必须对用户可见，不得让用户以为「桌面有的手机也有」。
- 原型**不含**任何真实加密、同步与存储逻辑；所有数据为前端 Mock。
- 原型说明更新后，同步维护本文件与对应端的 `README.md`（`v2.0/README.md`、`mobile/README.md`）的页面与交互清单。

## 本地验证

```powershell
# 方式一：直接双击
start prototype/index.html

# 方式二：静态服务器（任一端）
python -m http.server 8080 --directory prototype/v2.0      # 桌面端
python -m http.server 8080 --directory prototype           # 再访问 /mobile/
```

无 Lint / 测试 / 构建命令。检查项为与 `docs/` 索引及术语表的一致性、以及各端 `README.md` 中页面与弹窗清单的可达性。
