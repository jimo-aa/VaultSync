# VaultSync 桌面端高保真原型

基于 `docs/03-前端设计.md`、`docs/04-前端展示形式.md` 及 05-01～05-06 模块设计文档实现的 HTML+CSS 原型。
纯静态、零依赖、无构建：**直接双击 `index.html` 即可在浏览器中打开**（也可挂在任何静态服务器上）。

## 演示口令

| 口令 | 效果 |
| --- | --- |
| `1234` | 主密码解锁 → 真实保险箱 |
| `88888888` | 伪装密码 → 伪空间（空保险箱，真实数据隔离） |
| 任意其他输入 3 次 | 触发暴力破解保护（30s 延时） |

「生物识别」按钮模拟 Windows Hello 认证流程。

## 页面与交互清单

- **锁屏**：转盘锁动效（签名元素）、密码/生物识别解锁、忘记密码（安全重置说明）
- **保险箱**：资源管理器式文件交互——单击选中、Ctrl/Shift 多选、双击打开、右键菜单操作；网格 / 列表 / 分栏三种视图、面包屑与文件夹导航（工作 → 2026）、全局搜索（文件名 / 标签 / 全文命中高亮）、导入（进度模拟）、新建文件夹、标签管理
- **文件详情弹窗**：元数据、加密信息（FSKey / nonce 前缀 / 块数）、预览、导出、阅后即焚分享（一次性会话时间线）、隐写嵌入、重命名、安全擦除（多选支持批量擦除，输入确认短语 → 传播删除）
- **设备**：设备列表（在线态）、配对请求横幅、配对向导（扫码二维码 / 邀请码 / 手动输入 → 指纹核验 → 完成）、设备详情（信道信息）、解除配对、远程销毁（签名指令 + 延迟销毁语义）
- **同步**：总览统计卡、传输队列（上传 / 下载 / 冲突分节、进度动画、暂停恢复）、单文件同步详情抽屉（CDC 块矩阵、断点续传点）、冲突解决（保留两版本 / 择一）、同步策略（时段 / 带宽 / WiFi / 排除文件夹）
- **安全中心**：六项检测仪表、审计日志（分类筛选、链式哈希、条目详情、校验审计链、加密导出）、紧急销毁（范围选择 → 确认短语「销毁」→ 全屏销毁进度 → 回到锁屏）、隐写术启用开关
- **隐写术**（启用后导航栏出现）：嵌入向导（容量估算 → 进度）、提取向导、容量参考墙
- **设置**：主密码管理（强度评估、零重加密说明）、生物识别绑定、自动落锁规则、伪装入口配置、同步策略、深浅色主题切换（实时生效）
- **全局**：通知中心（分级通知）、Toast 反馈、锁定转场、右键菜单、ESC 关闭弹层 / 清除选中、Ctrl+A 全选、Ctrl+K 聚焦搜索、`prefers-reduced-motion` 支持

## 文件结构

```
prototype/
├── index.html   # 全部页面骨架、弹窗、抽屉、SVG 图标库
├── styles.css   # 设计 Token（docs/03 §5）+ 全部组件样式，支持亮/暗主题
└── app.js       # Mock 数据（文件系统/设备/同步/审计）+ 状态机与交互逻辑
```

## 设计说明

- 色彩、字号、间距、圆角均取自 `docs/03-前端设计.md` 的 Design Token 表（暗色 `#10131A` 底 + 香槟金 `#D9B25F` 点缀，语义色四类）。
- 字体：界面 Segoe UI / PingFang SC / Noto Sans SC；数据与哈希用 Cascadia Code / JetBrains Mono 等宽。
- 本原型不含任何真实加密、同步与存储逻辑，仅用于交互与视觉验收；所有数据为前端 Mock。
