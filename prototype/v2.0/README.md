# VaultSync V2.0 桌面端高保真原型

> 设计基线：`docs/v2.0/`（现行）。上一代原型冻结在 `prototype/v1.0/`。
> 纯静态、零依赖、无构建：**直接双击 `index.html` 即可在浏览器中打开**（也可挂在任意静态服务器上）。
> 全部为 Mock 数据，不含任何真实加密、同步与存储逻辑。

---

## 一、演示口令

| 口令 | 效果 |
| --- | --- |
| `1234` | 主密码解锁 → 真实保险箱 |
| `88888888` | 伪装密码 → 伪空间（与真空间信息架构逐一对应） |
| 任意其他输入连续 3 次 | 触发暴力破解保护（错误码 2，30 s 冷却倒计时） |

「生物识别」按钮模拟 Windows Hello 流程（不写入任何真实平台安全区）。

**演示控制台**（侧栏底部 ✨ 图标 / 命令面板 → 「打开 值班模式（演示）」）可实时切换：
只读降级（码 9）· 维护态（码 10）· 需要恢复（码 11）· 事件流溢出（23）· 同步中 · **全部能力位**。
用于逐项验收「能力三档」与「状态透明」的呈现纪律。

## 二、目录结构

```
prototype/v2.0/
├── index.html              # 外壳 + 脚本装载顺序（刻意不用 ES Module，保证 file:// 双击可用）
├── assets/
│   ├── tokens.css          # Design Token V2（12 沿用 + 4 新增语义色，亮/暗双主题）
│   ├── base.css            # reset / 排版层级 / 工具类 / 动效关键帧
│   ├── components.css      # 组件层（含 V2.0 新增 7 件）
│   └── views.css           # 外壳、锁屏、保险箱三视图、命令面板、通知中心
├── js/
│   ├── core.js             # 工具 / 格式化(intl) / 14 错误码 / R1–R17 映射 / 能力位 / 状态仓库
│   ├── ui.js               # UI 原语：按钮 表单 下拉 模态 菜单 Toast 环 甘特 套餐卡 …
│   ├── data.js             # Mock 语料（字段名对齐各模块载荷定义）
│   ├── views-vault.js      # 锁屏之外的保险箱域：三视图 + 详情 12 分区 + 导入/导出/擦除/检索
│   ├── views-sync.js       # 设备与配对 / 同步总览 / 队列 / 冲突 / 策略 / 阅后即焚
│   ├── views-security.js   # 安全中心四 tab / 审计 / 擦除强度 / 紧急销毁 / 隐写术 / 全屏告警
│   ├── views-system.js     # 设置 / 恢复向导 / 轮换 / 迁移 / 授权与订阅 / 关于 / 诊断
│   └── app.js              # 外壳 · 哈希路由 · 锁屏 · 通知中心 · 命令面板 · 演示控制台
├── _requirements/          # 从 docs/v2.0 提取的 UI 面清单（实现依据，非交付物）
└── README.md
```

**为什么不用 ES Module**：`import` 在 `file://` 下会被浏览器 CORS 策略拦截，双击打开即失效。
因此全部使用经典脚本，按依赖顺序加载，模块间通过全局 `VS` 命名空间通信。

## 四、实现纪律（与设计文档一一对应）

1. **能力三档**（`03` §1.2）：能力位未置位时**整块不渲染**，其次置灰，**绝不降级为假装成功**。演示控制台可逐位切换验收。
2. **错误码全 14 码**（`03` §3.2）：`VS.ERR` 统一定义文案与人话；码 12 用 info 语气而非红色错误态；码 9 只切只读横幅、**不弹错误框**。
3. **中继错误空间独立**（`08` §3.4、AGENTS.md）：`VS.RELAY_ERR` 定义 R1–R17 的**用户可见映射**，界面不得原样显示 R 码。
4. **擦除强度如实**（`05-02` §三.4/§四.3）：徽标显示引擎原值；`crypto_only` / `unknown` 文案必含「**介质覆写未执行**」；「安全擦除」字样仅在 `platform_secure` + 平台安全删除位成立；物理删除失败显示「**介质擦除待完成**」。
5. **写冻结矩阵**（`03` §3.1、`05-02` §三.5）：`VS.derive.denyWrite()` 是唯一判据，只读与维护态的可用/禁用清单在只读弹窗中逐条列出。
6. **不谎报能力**（`04` §3.6）：无接口的可视化整行不渲染（如卷容量），有接口的标注来源（六项检测仪表逐项给出接口名 / 事件类型）。「设计保证」档用虚线描边徽标标注。
7. **intl 强制**（`03` §6.1）：日期 / 数字 / 体积 / 相对时间 / 速率全部走 `VS.fmt`，禁止手写拼接。
8. **原型约束**：纯静态、零依赖、无框架、无构建；文件列表单击选中、双击打开、右键菜单；二级界面一律弹窗。

## 五、与 V1.0 原型的差异（破坏性重构清单）

| 项 | V1.0（`prototype/v1.0/`） | V2.0 |
| --- | --- | --- |
| 文件组织 | 单文件 `index.html` + `styles.css` + `app.js` | 按域拆分为 4 个视图模块 + 内核/原语/数据分层 |
| 设计 Token | 12 个沿用 Token | 追加 `maintenance` / `erase` / `quarantine` / `stale` 四语义色与 soft 变体；`accent` 亮色改以实现值 `#B98F2E` |
| 页面 | 6 个一级页 | 13 个路由 + 4 个专用路由（恢复 / 轮换 / 迁移 / 告警） |
| 新组件 | FileCard / ProgressSync / SecurityBadge / StepAuth / ConfirmWipe / Snackbar / PeerRow | 追加 `QueueRow` / `TransferRing` / `MaintenanceBanner` / `EraseClassBadge` / `RecoveryWizard` / `PeerDiscoverCard` / `ConflictPair` |
| 状态呈现 | 无维护 / 恢复 / 只读降级 | 三态维护横幅、只读降级横幅（不弹框）、恢复向导、事件流溢出重建 |
| 配对 | 手填 `ip:port` | 发现式优先（发现卡）+ 邀请码 / 扫码 / 手动兜底 |
| 通知 | 四级 Toast | 三级分发，`danger` 升级为全屏强告警 `/alarm`（无关闭按钮、Esc 无效、语义动词按钮） |
| 授权 | 无 | 授权与订阅（**无商业订单/支付/试用/发票** —— 文档未定义，故不虚构；仅跨设备指令信封） |
| 隐写 | 单图嵌入 / 提取 | 跨图多分片 + 容量账本 + 逐图占用 + 缺片列表；UI **不自行计算容量** |

## 六、明确未实现 / 不虚构的部分

原型严格跟随 `docs/v2.0` 的边界，以下内容**文档未定义，因此原型不虚构**：

- 商业订单、购物车、支付方式、结算、退款、发票 —— `12` §1.3 列为非范围；套餐价格使用可配置占位。
- 试用期 —— `12` §6.3 明确反对；授权页无任何试用倒计时。
- 语音 / 视频通话界面 —— `05-04` 的「通信」仅指 Noise 信道与一次性 burn 分享通道，无音视频 UI 描述。
- 「只存不解」节点 —— `13` 记录为架构空白但未立项，原型不提供可操作 UI。
- 「异地检测」落锁 —— 架构上无该接口，设置页该项 **⛔ 不渲染**。
