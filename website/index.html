一个应用，全套能力

不是「网盘 + 一把锁」，而是从密钥体系到传输协议全程自持的加密文件系统。

加密保险箱

CDC 分块 + AES-256-GCM，每文件独立密钥。加密块 = 同步块 = 传输块，局部修改不触发全文件重加密。

双因子密钥体系

主密钥由 CSPRNG 生成且永不变更；主密码（Argon2id）与生物识别只是两把解封钥匙。改密码零重加密。

P2P 设备同步

自研 Noise 帧协议 + mDNS 发现 + 配对短码 + NAT 打洞；打洞失败时由只转发密文的自建中继兜底。

密文侧全文检索

HMAC 倒排索引 + CJK bigram，明文索引永不落盘——能搜到，但磁盘上看不到。

隐写术引擎

PNG LSB 隐写，载荷加密先行。把机密藏进一张普通图片，而非只靠口令保护。

链式哈希审计日志

全部安全敏感操作写入防篡改的链式审计日志，随时校验、加密导出——你可验证自己没被篡改。

伪装空间

独立主密钥的第二保险箱。胁迫场景下交出它，真实数据不可证伪地不存在。

安全擦除与紧急销毁

密钥销毁优先的加密擦除，按介质如实声明强度；本机销毁可联动全设备离线指令队列。

密钥轮换

单文件 / 文件夹 / 全库主密钥轮换，轮换会话可中断续做，并跨设备传播。

零信任安全模型

明文与密钥只存在于 Rust 核心引擎层；界面层拿到的只是一个不透明的会话句柄。

密钥永不出引擎

主密钥（MK）由密码学安全随机数生成、永不变更，解封只发生在引擎内部。主密码与生物识别只是两把 KEK，用于解封 MK 的 wrapped 副本；文件使用每文件独立的 FSKey 加密。

中继只转发密文

官方与自建中继均不落盘、不解密。跨 NAT 同步时，中继看到的只是它读不懂的数据块。

证据先行

任何对外声称的安全能力都要求运行时接口与可复现证据（当前引擎已有 234 项端到端断言、75 个 FFI 导出）。没有接口的能力，界面上如实说没有。

无账号 · 无遥测

引擎零遥测、无遥测端点、无持续回连。除你主动触发的中继额度兑换外，客户端不发出任何出站请求。
