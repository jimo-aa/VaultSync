环境依赖

Flutter SDK（桌面端）与 Rust toolchain（cargo）。克隆仓库后：

git clone https://github.com/jimo-aa/VaultSync.git cd VaultSync/app flutter pub get flutter run -d windows

首次运行

锁屏输入的密码即成为主密码（≥8 位且强度达标）。主密码不可找回——忘记密码 = 数据不可恢复。开发阶段请勿存放唯一副本的重要数据。
