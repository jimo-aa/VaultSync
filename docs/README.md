## 三、对象模型与统一术语

为保证跨文档一致，先统一术语。各模块文档将沿用下表命名。

| 术语 | 定义 |
| --- | --- |
| Vault | 加密保险箱，指整个加密存储容器 |
| Master Key / MK | 主密钥，32B CSPRNG 随机生成，**不依赖密码派生**，永不变更（泄露时按 `07` 轮换） |
| KEK | 密钥加密密钥（Key Encryption Key）。`KEK_pwd` 由主密码经 Argon2id 派生；`KEK_bio` 由平台安全区托管。MK 以"wrapped 副本"形式被 KEK 包装后存储 |
| Folder Sub-Key / FSK | 文件夹级子密钥，由 MK 经 HKDF-SHA256 派生 |
| File Session Key / FSKey | 文件级会话密钥，每个文件随机生成 |
| Chunk | 内容定义分块（CDC，FastCDC/Rabin），**加密块 = 同步块 = 传输块**，平均 64KB–256KB（按文件大小自适应） |
| Engine（核心引擎） | Rust 实现的 `.so`/`.dll`/`.dylib` 原生库，经 FFI 暴露给 Flutter |
| FFI | 前端与核心引擎之间的跨语言调用桥 |
| Peer / Device | 已配对设备，构成 P2P 网络中的节点 |
| Relay | 中继节点（官方公共 + 用户自建），仅转发密文，不落盘、不解密（见 `08`） |
| Stego | 隐写术相关能力（LSB） |
| 加密擦除 | 通过销毁密钥使密文不可恢复的删除方式，为现代 SSD 的首选擦除路径 |
| 零信任 | 不信任任何中间节点，全程密文流转 |

## 四、全局技术选型速览

| 层面 | 技术 | 说明 |
| --- | --- | --- |
| 客户端 UI | Flutter（Dart） | 跨平台桌面 + 移动端 |
| 状态管理 | Riverpod 2.x | 前端响应式状态与依赖注入 |
| 核心引擎 | Rust（Workspace） | 加密 / 同步 / 隐写 / 审计全部下沉原生层 |
| FFI 桥 | dart:ffi + 自动绑定生成 | 前后端类型安全的接口契约 |
| P2P 网络 | libp2p（rust-libp2p） | 直连 / DCUtR 打洞 / Circuit Relay v2 中继 |
| 隐私保护 | Argon2id / AES-256-GCM / HKDF / Noise / LSB / Zeroize | 密钥包装、加密、传输、隐蔽、擦除 |

**平台策略**：**桌面优先**（Windows / macOS / Linux 为主战场，性能与安全上限高）；移动端（Android / iOS）V0.2 跟进，后台同步受系统约束（见 `01` §七 NFR）。
