## 一、总览

开发按六个阶段推进，阶段内任务按依赖排序。每个任务有状态标记：

`[ ]` 未开始 ｜ `[~]` 进行中 ｜ `[x]` 完成 ｜ `[!]` 受阻（原因记入 `LOG.md`）

| 阶段 | 名称 | 目标 | 出口标准（DoD） |
| --- | --- | --- | --- |
| P0 | 工程奠基 | 仓库、规范、骨架可构建可测试 | CI 绿、两端 Hello World 跑通 |
| P1 | 加密内核 | `vault-crypto` + 密钥体系可用 | ✅ 2026-09-17 完成（MK/KEK 全链路测试 + FFI 端到端冒烟通过） |
| P2 | 保险箱与索引 | 文件加密存储、CDC 分块、检索 | ✅ 2026-09-17 完成（导入/导出/检索/擦除/分享端到端冒烟通过） |
| P3 | P2P 同步 | 设备配对 + 增量同步 + 中继 | 两设备真实同步、断点续传 |
| P4 | 前端完整化 | 六大模块 UI 对接真实引擎 | 原型所有交互有真实后端 |
| P5 | 加固与发布 | 审计、隐写、迁移、打包分发 | 威胁模型复核通过、双平台安装包 |

## 三、阶段 P1 — 加密内核

- `[x]` P1-1 `vault-crypto`：CSPRNG、Zeroize、AES-256-GCM、HKDF-SHA256 封装（2026-09-17 —— HKDF 依 RFC 5869 自实现，官方向量断言；Zeroizing 全链路密钥擦除）
- `[x]` P1-2 Argon2id 派生 `KEK_pwd`；MK 生成与 wrapped 副本存储（2026-09-17 —— 桌面参数 64MiB/t3/p2 + 16B salt；VSVB v2 头部：`MK_wrap_pwd` + verifier）
- `[x]` P1-3 平台安全区集成（Keychain / Keystore / Windows Hello）派生 `KEK_bio`，含降级路径（2026-09-17 —— keyring：Windows Credential Manager / macOS Keychain；Linux 无后端自动禁用生物识别路径，主密码不受影响；Hello 静默认证留 P5 加固）
- `[x]` P1-4 FSK 派生链（MK → FSK → FSKey）与零重加密的主密码更换流程（2026-09-17 —— HKDF 上下文分离（fsk/verifier）；改密码仅重生成 `MK_wrap_pwd`，MK 不变断言通过；FSK→FSKey 落地为 P2 文件加密时的派生调用）
- `[x]` P1-5 暴力破解防护（延时 / 计数）、伪装密码（伪空间）逻辑（2026-09-17 —— 引擎侧按父目录域计数，3 次起 30s 指数递增至 15min；伪装=独立保险箱文件独立 MK；Dart 锁屏冷却倒计时）
- `[x]` P1-6 密钥格式版本化字段（为 `docs/07` 迁移预留）（2026-09-17 —— magic `VSVB` + format_ver=2 / kdf_ver / cipher_suite / flags；向前拒绝更高版本，未知尾部字节兼容）

### P1 附带交付

- FFI 完整绑定（dart:ffi，Argon2 调用在后台 Isolate 执行避免 UI 冻结）
- `app/tool/ffi_check.dart` P1 端到端冒烟（20 项断言：创建/解锁/冷却/改密/生物识别全链路）

## 四、阶段 P2 — 保险箱与索引

- `[x]` P2-1 Vault 容器格式与索引（2026-09-17 —— 每文件独立密文容器 VSEF v2（Header+加密元数据+数据区，docs/05-02 §3.3）；索引 VSIX v2 整体 AEAD 落盘（SQLite 留待并发场景引入，LOG 有记录）；条目含名称/大小/时间/标签）
- `[x]` P2-2 CDC 分块（FastCDC，64KB–256KB 自适应）+ 块级加密，三者同块（2026-09-17 —— fastcdc v2020 StreamCDC；小文件 16KB 自适应；确定性 nonce=prefix32∥counter64，块序号 AAD，密文 SHA-256 块清单）
- `[x]` P2-3 导入 / 导出 / 重命名 / 文件夹树（2026-09-17 —— 流式恒定内存；整文件 SHA-256 终验；重命名重建倒排；递归删除文件夹）
- `[x]` P2-4 全文检索（密文侧可检索方案，禁止明文索引落盘）（2026-09-17 —— SSE-lite：HMAC(搜索密钥,归一化词) 倒排；拉丁分词+CJK bigram；内容采样 1MB，NUL 判定二进制跳过；仅返回脱敏元数据）
- `[x]` P2-5 安全擦除（密钥销毁路径 + 块引用回收）、阅后即焚分享（2026-09-17 —— 每文件容器使擦除=容器删除（密文与密钥同灭），secure 时先单次覆写；分享=令牌 HMAC+TTL+次数，耗尽先于令牌校验防爆破）
- `[x]` P2-6 大文件 / 特殊文件（空文件、并发导入）边界用例（2026-09-17 —— 空文件/8MB 多块/二进制/重命名后检索/递归删除均有测试；并发导入由会话内串行 Mutex 保证，跨进程并发留 P3）

### P2 附带交付

## 八、面板维护规则

- 完成任务时勾选并在 `LOG.md` 末尾追加一条记录（日期 + 任务号 + 摘要）。
- 受阻任务标记 `[!]`，原因与临时方案记入 `LOG.md`，不在此处展开。
- 新增任务只能在本面板追加，任务号按阶段递增（如 P2-7）。
- 阶段全部完成后在总览表标注完成日期。
