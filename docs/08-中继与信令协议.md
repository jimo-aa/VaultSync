# VaultSync 中继与信令协议规范

> 文档编号：08 ｜ 版本：V0.2 ｜ 定位：**横切专项文档（不含源码）**

---

## 一、目的与归属决策

跨 NAT 场景下，直连与打洞（DCUtR）失败时需要中继/信令节点。**决策（ADR-006）：官方运营公共中继集群，同时开放协议允许任何人自建中继**。零信任边界：中继只转发密文比特，不落盘、不解密、不持有任何密钥；其作恶上限为 DoS 与流量分析（见 `06` T2）。

技术基座（复用 rust-libp2p 生态，不自研）：

| 能力 | 协议 |
| --- | --- |
| 中继转发 | Circuit Relay v2（带资源限制与保留票据） |
| NAT 打洞 | DCUtR（直接连接升级协议） |
| 节点发现（跨网） | Rendezvous（ rendezvous 点可与中继同部署） |
| 传输加密 | 底层 Noise（libp2p 传输层）+ 应用层逐块 AEAD，双层 |
| 流量辨识对抗 | 可选填充（信令与数据帧统一填充到分级档位） |

---

## 二、中继的不可见性保证

1. **不落盘**：中继进程无持久化存储（tmpfs 运行），转发缓冲即用即弃；
2. **不解密**：中继不参与任何密钥协商（Noise 跑在两端之间，中继仅看到外层 relay 帧）；应用层数据本就是 FSKey 密文；
3. **不溯源**：中继日志仅含限速所需的匿名计量（字节数、连接时长），不含设备 ID、公钥指纹、目标地址明文；
4. **信令封装**：所有业务信令（配对/同步/删除/状态）在两端 Noise 信道内传输并带 HMAC 与单调序号（`05-04`），中继只见不透明帧。

## 三、接入与鉴权

### 3.1 官方中继

- 免费、匿名接入，**不要求账号**（与零信任一致）；
- 匿名性保护：客户端经中继只暴露"中继侧临时连接 token"，真实设备身份封装在内层加密信道；
- Circuit Relay v2 原生资源限制：单连接带宽/时长/并发上限，防滥用（防被当作代理/放大攻击跳板）。

### 3.2 自建中继

- 协议与官方完全一致（同一份本文档规范）；
- 自建部署需配置**接入 token**（部署者自选分发方式：家庭/团队私有中继凭 token 限制接入）；
- 官方中继集群地址内置客户端，用户可在设置中增删自建中继、可完全禁用官方中继（禁用后仅局域网/打洞直连）。

---

## 四、信令协议要点

1. **序号防重放**：每对设备间维持单调递增序号，乱序/重复即丢弃并触发入侵检测（`05-04` §4.2）；
2. **高优先级队列**：销毁指令（`05-06` §5.1）永远排在队列首位，设备上线后先于一切业务消息校验执行；
3. **指令签名**：删除/销毁/解配等破坏性信令必须携带发起方设备长期身份密钥签名，接收端验签后执行；
4. **时钟与超时**：信令带时间戳 + 60s 容差窗口，超窗丢弃（离线设备追上后由序号机制保证旧信令不误执行——销毁指令除外，其语义为"到达即执行"）。

## 五、降级矩阵

| 路径 | 条件 | 元数据暴露 |
| --- | --- | --- |
| 局域网 mDNS 直连 | 同网段 | 无中继参与 |
| DCUtR 打洞直连 | 双端 NAT 可穿透 | 无中继参与 |
| 中继转发 | 打洞失败 | 中继见密文长度/时序（可选填充缓解） |
| 全部失败 | 完全离线 | 不同步，本地可用性不受影响；上线后自动追赶 |

---

## 六、测试

- 中继作恶模拟：篡改/重放/存储帧，验证两端检测与拒绝；
- DCUtR 打洞各类 NAT 组合（含对称 NAT 必败场景回落中继）；
- 自建中继 token 鉴权与禁用官方中继后的行为；
- 销毁指令高优先级验证（上线后先于同步执行）；
- 填充档位下流量分析不可区分文件类型（抽样统计测试）。
