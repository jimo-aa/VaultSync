# VaultSync 前端设计

> 文档编号：03 ｜ 版本：V0.1 ｜ 定位：**设计文档（不含源码）**
> 内容：信息架构、页面线框图（ASCII）、主题设计与组件规范

---

## 一、前端设计目标

- **体验接近普通云盘**：用户感知不到加密与同步的复杂过程（`计划书V0.1` 愿景）。
- **安全状态透明**：在关键动作（解锁、同步、擦除、紧急销毁）节点给出明确反馈。
- **跨平台一致**：桌面（宽布局）与移动（窄布局）共用一套设计语言与状态模型。
- **优雅呈现机密性**：使用克制、沉稳的视觉语言，传达"可靠与安全"的情绪。

---

## 二、信息架构与导航结构

信息架构与导航结构如下：

- **锁屏 / 解锁入口**
  - 解锁 → **主壳层**；
  - 伪装密码 → **伪空间（空白保险箱）**。
- **主壳层**下设五个 Tab：
  - **保险箱**：文件夹/标签视图、文件详情/预览、导入/导出、搜索/全文检索；
  - **设备**：设备列表、配对流程（扫码/邀请码/手动）；
  - **同步**：同步状态总览、单文件同步详情；
  - **安全中心**：审计日志、入侵检测告警、紧急销毁、隐写术入口（默认隐藏）；
  - **设置**：主密码/生物识别管理、自动落锁规则、同步策略/带宽/时段、伪装入口配置。

**导航约定：**
- 桌面端：左侧为常驻导航栏（宽屏），内容区右侧自适应。
- 移动端：底部 Tab 栏（窄屏），页面栈内嵌二级导航。
- 未解锁时仅展示 `Entry` 全屏锁屏；除设置语言等极少量项的"任意界面"维持锁定态。

## 三、状态设计（锁 / 会话 / 同步）

### 3.1 全局安全状态机

状态迁移如下（初始即处于 Locked）：

- `Locked → Unlocking`：输入主密码 / 生物识别；
- `Unlocking → Unlocked`：验证通过；
- `Unlocking → Locked`：验证失败 / 暴力破解；
- `Unlocked → Locked`：空闲超时 / 锁屏 / 手动 / 离开应用 / 异地检测 / 紧急锁定；
- `Locked → Dummy`：输入伪装密码；
- `Dummy → Locked`：退出伪空间。

### 3.2 三个并行状态维度

| 维度 | 取值 | 前端表现 |
| --- | --- | --- |
| 锁状态 | Locked / Unlocking / Unlocked / Dummy | 决定是否展示文件明文元数据 |
| 会话 | Active / Expired / Revoked | 决定安全 API 是否可用 |
| 同步 | Idle / Syncing / Paused / Error / Offline | 决定进度条、角标与提示 |

> 前端**只展示脱敏后的元数据**（文件名可在解锁后显示），密钥与密文由 Engine 持有。

**交互流程：** 主密码 → 校验 → 成功进主壳；伪装密码 → 进伪空间。用户在锁屏输入密码后：

- **真实主密码**：Engine 校验通过 → 展示保险箱；
- **伪装密码**：通向伪空间 → 展示空保险箱；
- **失败**：返回失败与延时 → 错误提示 / 暴力破解计数。

### 4.3 设备列表 + 配对流程

**设备列表（节点视图）：**

```
┌──────────────────────────────────────┐
│ 设备                       [+ 配对]  │
│ ──────────────────────────────────── │
│ ● 这台电脑          [在线]  主节点    │
│ 💻 WorkBook           已配对  上次同步 2m │
│ 📱 Phone-01           已配对  未同步   │
│ ⏳ nearby: LumiaDevice  待配对  [配对]  │
│ ──────────────────────────────────── │
│ + 手动添加设备ID / 公钥                 │
└──────────────────────────────────────┘
```

**配对交互流程：**

1. 设备A 生成二维码（公钥 + 设备ID）并展示；
2. 设备B 扫码 / 读取后向设备A 发起配对请求；
3. 设备A 显示配对确认（核验指纹），确认后进行双向认证；
4. 认证通过后建立加密信道，双方各自写入节点清单并记审计。
> 跨网络无扫码场景走"邀请码"/"手动添加"，流程一致，仅输入载体不同。

## 五、主题设计系统

### 5.1 设计语言基调

- **情绪**：可靠、克制、略带"暗室/金库"的科技感。
- **关键词**：深色低饱和、暖金属点缀色、干净留白、聚焦安全语义色。

### 5.2 色彩系统（Color Tokens）

采用 **亮/暗双主题**，以下为核心 Token（色值取 Design Token 命名法）：

| Token | 亮色 | 暗色 | 用途 |
| --- | --- | --- | --- |
| `color.background` | `#F7F8FA` | `#10131A` | 全局底 |
| `color.surface` | `#FFFFFF` | `#1A1F2B` | 卡片/面板 |
| `color.surfaceAlt` | `#EEF0F4` | `#242A38` | 次级面板 |
| `color.border` | `#E3E6EC` | `#2E3544` | 分隔/描边 |
| `color.text.primary` | `#1A2333` | `#E8EBF2` | 主文本 |
| `color.text.secondary` | `#5A6A7F` | `#8A94A6` | 次级文本 |
| `color.accent` | `#C7A24A`（香槟金） | `#D9B25F` | 品牌强调、临检点亮 |
| `color.accentAlt` | `#2050E0` | `#4C7BFF` | 动作主色 |
| `color.success` | `#1E9B5A` | `#34C77B` | 同步成功 |
| `color.warning` | `#D9820B` | `#F0A63C` | 风险提示 |
| `color.danger` | `#C53A3A` | `#E55252` | 危险/销毁 |
| `color.encrypt` | `#7A5CC0` | `#9B7FE0` | 加密状态标识 |

> 语义色在安全类状态（加密、危险、隐身）上强调，避免彩度泛滥。

### 5.3 字体与排版（Typography）

| 层级 | 字号/字重 | 用途 |
| --- | --- | --- |
| Display | 32 / 半粗 | 锁屏品牌、应急页 |
| H1 | 24 / 半粗 | 页面标题 |
| H2 | 18 / 半粗 | 区块标题 |
| Body | 14 / 常规 | 正文 |
| Caption | 12 / 常规 | 辅助说明、元数据 |
| Mono | 13 / 等宽 | 哈希、ID、审计数据 |

- 推荐字体族：中文 `PingFang SC / Noto Sans SC`；等宽 `JetBrains Mono / Roboto Mono`。
- 常规字号最低不小于 12，触控目标不小于 44×44。

### 5.4 间距 / 圆角 / 阴影（Spacing & Elevation）

| Token | 值 | 用途 |
| --- | --- | --- |
| `sp.1` | 4 | 元素内间距 |
| `sp.2` | 8 | 元素间间距 |
| `sp.3` | 12 | 卡片内边距 |
| `sp.4` | 16 | 区块间距 |
| `sp.5` | 24 | 页边距/大间距 |
| `radius.sm / md / lg` | 8 / 12 / 16 | 控件/卡片/弹层 |
| `elev.1 / 2 / 3` | 柔和/中/强 | 悬浮、弹窗、遮罩 |

### 5.5 图标与视觉元素

- **隐喻**：以"保险箱 / 锁 / 盾 / 眼睛/R2R"为核心隐喻；功能图标线性风格，加密/危险态可用填充强调。
- **加密可视化**：文件卡片右上角小锁徽标，未解锁时统一灰化占位。

### 5.6 关键组件规范

| 组件 | 规范要点 |
| --- | --- |
| FileCard | 缩略图（加密缓存）＋ 名称 ＋ 大小/时间 ＋ 锁徽标 |
| ProgressSync | 线性/环形进度，支持暂停/取消，配速度与剩余项 |
| SecurityBadge | 语义色标签（加密/审阅/危险/隐身） |
| StepAuth | 主密码/伪密码/生物识别多步骤向导 |
| ConfirmWipe | 二次强确认弹层（需输入确认短语）触发紧急销毁 |
| PeerRow | 设备头像＋在线态＋上次同步时间＋操作 |
| Snackbar | 同步/擦除/告警的轻量提示 |

## 六、无障碍与本地化

- 无障碍：足够对比度（语义色 ≥ 4.5:1），触控目标 ≥ 44px，支持屏幕朗读（语义标注），动画可关闭（减少动态）。
- 本地化：所有文案走 i18n 资源表；首版支持 简体中文 / English；日期与数字跟随系统地区。

---

## 七、前端性能与安全实践

| 实践 | 说明 |
| --- | --- |
| 大列表虚拟化 | 保险箱网格/列表使用懒加载 + 分页，避免一次性渲染大量卡片 |
| 缩略图加密缓存 | 明文缩略图仅存内存缓存，锁定时清除 |
| 异步不受阻 | 所有 FFI 调用异步化，UI 线程不执行加解密 |
| 敏感数据最小化 | 前端不负责任何明文持久化；搜索过程使用 Engine 检索加密索引 |
| 进程级保护 | 移动端关闭屏幕截图/允许后台截取白名单由安全策略配置 |
