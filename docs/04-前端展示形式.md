# VaultSync 前端展示形式

> 文档编号：04 ｜ 版本：V0.1 ｜ 定位：**设计文档（不含源码）**
> 内容：多端适配、视图/列表形式、数据可视化、动效与交互形式、后台/通知展示

## 一、展示形式总览

"展示形式"指**同一核心引擎在不同设备、尺寸、网络与状态下的呈现与交互方式**。VaultSync 采用"一套内核、多端外壳"策略，前端根据形态自适应。

| 端 | 形态 | 主导航 | 主内容布局 |
| --- | --- | --- | --- |
| 桌面（Win/macOS/Linux） | 宽屏窗口 | 左侧常驻导航栏 | 网格 / 列表双视图，多栏工具条 |
| 平板（iPad/Android Pad） | 中宽屏 | 左侧导航（可折叠） | 网格为主，分栏预览 |
| 手机（iOS/Android） | 窄屏 | 底部 Tab | 列表/单栏，抽屉导航 |
| 折叠屏/小窗 | 自适应 | 随宽度降级 | 上为导航、下为内容 |

**自适应模式：** 按窗口 / 屏幕宽度选择布局：

- ≥ 1280：桌面布局（左侧大栏导航 + 网格）；
- 720–1280：平板布局（可折叠侧栏 + 分栏）；
- < 720：手机布局（底部 Tab + 单栏）；
- > 1820：超宽（多列网格 / 侧边详情面板）。

## 二、视图（View）与列表（List）形式

### 2.1 保险箱的三种视图

| 视图 | 说明 | 适用端 |
| --- | --- | --- |
| 网格视图（Grid） | 缩略图卡片，大图预览友好 | 桌面/平板 |
| 列表视图（List） | 紧凑行（图标+名称+大小+时间+状态），信息密度高 | 全部，尤其移动 |
| 分栏视图（Split） | 左为文件夹树、右为文件网格或详情 | 桌面宽屏 |

**可切换示例（ASCII）：**

```
视图切换:  [网格 ▓▓] [列表 ☰] [分栏 ▤]     (仅在宽屏显示分栏)

列表视图示例 ↓
┌────────────────────────────────────────────────────────┐
│ 名称       │ 类型 │ 大小    │ 修改时间   │ 状态    │ 操作 │
│ report.docx │ 文  │ 1.2 MB │ 09-15 10:02│ 已同步  │ ⋯ │
│ photo.png  │ 图  │ 3.4 MB │ 09-14 08:11│ 待同步  │ ⋯ │
└────────────────────────────────────────────────────────┘
```

### 2.2 文件/文件夹展示要素（列表行）

- 首图标（按 MIME 类型映射）→ 名称 → 大小/类型 → 修改/同步时间 → 状态徽标（已加密/待同步/冲突/审阅中）→ 操作菜单。
- 加密态用 `encrypt` 语义色的小锁徽标标识。

### 2.3 搜索与全文检索展示

- 顶部搜索框输入即搜；结果按"文件名 / 标签 / 全文命中"分组。
- 命中摘要高亮（脱敏片段），点击跳转文件详情。
- 未解锁时不提供搜索（触发锁屏）。

## 三、数据可视化展示

### 3.1 同步状态可视化

| 形态 | 展示 |
| --- | --- |
| 总览页 | 汇总卡片：在线设备数、待同步项、冲突数、通道速率 |
| 单项进度 | 线性进度条 + 百分比 + 速度 + 剩余项数 |
| 环形图 | 某文件的同步完成比（宽屏辅助） |
| 仪表盘 | 带宽、已同步量、存储占用（安全中心） |

**同步仪表盘（示意）：**

- **上传统计**：↑ 2.1 MB/s，18 项进行中；
- **下载统计**：↓ 800 KB/s，6 项下载；
- **存储**：已加密 42 GB，占用 46%。

### 3.2 安全状态可视化

- 用**语义色仪表牌**表示：Overall（正常/注意/危险）、各检测项（暴力破解、异常设备、文件完整、内存泄露）逐项绿/黄/红。
- 审计日志以**时间线/表格**展示，条目含时间、动作、对象、来源设备、结果。

## 四、动效与交互形式

### 4.1 动效原则

- **克制**：动效服务于安全状态反馈，不喧宾夺主。
- **反馈先行**：解锁/锁定/擦除等敏感动作必须有明确的状态反馈与完成确认。
- **可关闭**：支持"减少动态"，照顾可访问性。

### 4.2 各关键动效

| 场景 | 动效 |
| --- | --- |
| 解锁成功 | 保险箱钥匙点亮 + 淡入内容 |
| 锁定 | 内容淡出 + 快速遮罩回锁屏 |
| 同步 | 卡片/图标上进度环或进度条 |
| 同步完成 | 短促成功打钩淡入 |
| 紧急销毁 | 强红告警 + 确认短语输入 + 销毁进度 |
| 空态 | 引导插画 + 主 CTA |

## 五、后台与通知展示形式

### 5.1 后台任务展示

| 任务 | 前台展示 | 后台展示（移动） |
| --- | --- | --- |
| 自动同步 | 进度列表实时刷新 | 系统通知（摘要：完成 N 项/冲突） |
| 断点续传 | 显示暂停/恢复 | 锁屏后静默恢复，完成后通知 |
| 紧急销毁 | 全屏销毁进度 | 锁屏上单向指令（不可被普通操作取消） |

### 5.2 通知分级

| 级别 | 触发 | 展示 |
| --- | --- | --- |
| info | 正常同步完成 | 低打扰 Banner |
| warn | 暴力破解计数、配对请求 | 应用内告警条 + 可选系统通知 |
| danger | 入侵检测、紧急销毁 | 全屏强告警，需显式确认 |

## 六、各端展示差异矩阵

| 能力 | 桌面 | 平板 | 手机 |
| --- | --- | --- | --- |
| 导航 | 左侧栏 | 可折叠侧栏 | 底部 Tab |

| 后台同步 | 常驻 | 受管 | 受管（电池保护） |
| 生物识别 | 平台能力 | 平台能力 | 生物识别为主 |

## 七、使用参考（How the forms serve flows）

| 用户旅程 | 前端展示形式配合 |
| --- | --- |
| 首次使用 | 引导向导（密码设置→安全提示→完成） |
| 日常浏览 | 网格/列表切换、标签过滤、缩略图预览 |
| 多设备同步 | 同步总览 + 设备配对向导 + 冲突解决 |
| 安全应急 | 安全中心仪表盘 + 紧急销毁全屏流程 |
| 高级隐蔽 | 隐写术（默认隐藏）入口 + 批量嵌/提向导 |
