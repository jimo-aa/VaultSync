# VaultSync 模块详细设计：身份认证与安全入口

> 文档编号：05-01 ｜ 版本：V0.2 ｜ 类型：功能模块详细设计（**可含局部示例代码**）
> 对应计划书章节：§2.1
> V0.2 变更：密钥体系重构为 key-wrapping（MK 随机生成 + KEK 双路包装），主密码路径不再依赖硬件安全区。

---

## 一、模块职责

本模块是用户访问 VaultSync 的第一道防线，负责：

- 主密码设置与 KEK_pwd 派生（Argon2id）。
- 生物识别绑定 / 快捷解锁（KEK_bio 路径，可降级）。
- 自动落锁机制（空闲 / 离开 / 锁屏 / 异地）。
- 伪装入口与伪空间（胁迫场景）。
- 主密码修改（仅重包装 MK，数据零重加密）。

> 前端仅承担交互与展示；所有密钥派生、解封、校验、擦除逻辑在 `vault-crypto` / `vault-core` 内完成。

## 三、密钥包装体系设计（V0.2 核心）

### 3.1 体系总览

MK 与认证因素彻底解耦：

```
MK       = CSPRNG 随机 32B，永不变更（泄露才轮换，见 07）
KEK_pwd  = Argon2id(主密码, salt, 平台分级参数)     ← 密码路径包装钥匙
KEK_bio  = 平台安全区托管的随机 32B                 ← 生物识别路径包装钥匙
保险箱头部: MK_wrap_pwd = AEAD(KEK_pwd, MK)         ← 主副本
           MK_wrap_bio = AEAD(KEK_bio, MK)         ← 绑定生物识别后追加
verifier = HKDF(MK, "verifier")，独立于 MK 暴露面
```

设计要点：

- **改主密码** = 仅重新生成 `MK_wrap_pwd`，FSK / FSKey / 全部密文不变，毫秒级完成。
- **桌面无 TEE**：主密码路径不依赖任何硬件安全区，wrapped 副本存于本地保险箱头部文件（访问受文件系统权限保护）；生物识别路径在安全区不可用的平台（如 Linux 桌面）自动禁用对应副本。
- **生物识别与密码两副本互相独立**，任一路径丢失（改密码 / 安全区重置）不影响另一路径。
- **伪空间** = 第二套完全独立的 MK + 保险箱头部 + 密文文件，结构与真空间一致，抵抗"深度伪装检测"（对比文件结构可发现差异即失败）。

### 3.2 Argon2id 参数（按平台分级）

| 参数 | 桌面（首发基线） | 移动端 | 说明 |
| --- | --- | --- | --- |
| Memory | 64 MiB | 16 MiB | 抗 GPU/ASIC，低端机降级 |
| Iterations | 3 | 3 | 时间成本 |
| Parallelism | 2 | 1 | 按核心数 |
| Salt | 16B CSPRNG | 同左 | 每次设置随机 |
| Output | 32B | 32B | KEK_pwd 长度 |

> 参数持久化到保险箱头部明文区（KDF 参数非敏感），保证不同设备可校验同一密码。

## 四、关键子流程

### 4.1 首次设置主密码

1. 用户输入两次密码并确认，前端校验一致并给出强度提示；
2. 前端调用 `vs_setup(password)`；
3. `vault-core`：CSPRNG 生成 MK（仅存内存）→ 生成 16B salt → Argon2id 派生 KEK_pwd；
4. 生成 `MK_wrap_pwd` 与 verifier，连同 KDF 参数写入保险箱头部；
5. `zeroize(password, MK, KEK_pwd)` 清洗内存；
6. 向前端返回成功（不返回密钥）。

### 4.2 生物识别绑定

1. 用户主密码解锁一次（确保已持有 MK）。
2. 前端调平台生物识别（OS 完成生物认证，VaultSync 不接触生物特征）。
3. `vs_bind_biometric(session)` → Engine 生成 KEK_bio，交平台 Keychain/Keystore 托管（安全区仅存 KEK_bio，不存 MK）；Engine 追加 `MK_wrap_bio` 到保险箱头部。
4. 后续解锁走"安全区解封 KEK_bio"路径；安全区重置/不可用时该副本自动失效，主密码路径不受影响。

### 4.3 修改主密码

1. 解锁态下发起新旧密码；
2. Engine 校验旧密码（重派生 KEK_pwd 解封 MK 成功即证明正确）；
3. 用新密码派生新 KEK_pwd，重新生成 `MK_wrap_pwd`（salt 同步更换）；
4. MK、FSK、FSKey、密文全部不变；写审计。

### 4.4 自动落锁判定

解锁态下监听触发事件：

- 空闲超时 N 分钟 / 离开应用 / 屏幕关闭（锁屏）→ 锁定；
- 异地检测异常 → 锁定并告警；
- 锁定后执行 zeroize 密钥，会话令牌失效。

## 五、接口契约（伪代码 / Dart 示意）

> 以下为示意代码，体现前后端协同方式，非最终实现。

```dart
// 会话服务（前端服务层，仅编排，不持有密钥）
class AuthService {
  Future<bool> setup(String password) async {
    final ok = await ffi.vs_setup(password.encode()); // 引擎负责派生与包装
    await Zeroize().wipe(password);                    // 前端侧立即清洗口令内存
    return ok;
  }

  Future<Session> unlock({
    String? password,
    BiometricHandle? bio,
  }) async {
    return bio != null
        ? await ffi.vs_unlock_biometric(bio)   // 安全区路径，失败自动降级
        : await ffi.vs_unlock(password!);
  }

  Future<void> changePassword(String oldP, String newP) async {
    await ffi.vs_change_password(oldP.encode(), newP.encode()); // 仅重包装
  }

  Future<void> lock() => ffi.vs_lock();
}
```

```rust
// vault-crypto 示意（Argon2id 派生 KEK_pwd，注意输出是包装钥匙而非 MK）
fn derive_kek_pwd(password: &[u8], salt: &[u8]) -> Zeroizing<[u8; 32]> {
    let mut out = [0u8; 32];
    argon2::Argon2::new(
        Algorithm::Argon2id, Version::V0x13, Params::new(64 * 1024, 3, 2, None)?)
        .hash_password_into(password, salt, &mut out)?;
    Zeroizing::new(out)
}

// 解封 MK（示意）
fn unwrap_mk(kek: &[u8; 32], wrap: &MkWrap) -> Result<Zeroizing<[u8; 32]>> {
    let mk = aead_open(kek, &wrap.ciphertext, &wrap.nonce, &wrap.aad)?;
    Ok(Zeroizing::new(mk))
}
```

## 六、异常与越权处理

| 场景 | 处理 |
| --- | --- |
| 密码连续失败 | 触发延迟 + 暴力破解计数（联动安全中心） |
| 生物识别安全区重置 | `MK_wrap_bio` 标记失效，提示重新绑定；主密码路径不受影响 |
| 生物识别不可用 | 灰级使用，主密码始终可用 |
| 进入伪空间 | 会话标记为 Dummy；真实保险箱调用一律拒绝 |

## 七、审计与测试

- **审计**：设置/修改密码、生物识别绑定/解绑、锁定事件、伪装入口进入（仅记"进入了挂锁门"，不泄露真伪）→ 写 `vault-audit`。
- **测试**：Argon2id 向量、解封往返（wrap/unwrap）、改密码后旧密文可直接读取（零重加密断言）、安全区不可用降级路径、锁定后 Magic-Op 拒绝（负向断言）、zeroize 后缓冲无残留、异地检测触发正确。
